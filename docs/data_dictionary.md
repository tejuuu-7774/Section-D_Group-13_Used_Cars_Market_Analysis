# Data Dictionary

## Dataset
`vehicles.csv`

## Column Descriptions
| Column | Description |
|---|---|
| `id` | Unique identifier for each vehicle listing |
| `url` | Listing URL |
| `region` | Craigslist region where the listing was posted |
| `region_url` | Base URL for the listing region |
| `price` | Listed vehicle price in dollars |
| `year` | Vehicle model year |
| `manufacturer` | Vehicle manufacturer or brand |
| `model` | Vehicle model name |
| `condition` | Reported vehicle condition |
| `cylinders` | Number of engine cylinders |
| `fuel` | Fuel type |
| `odometer` | Vehicle mileage |
| `title_status` | Title condition or legal title status |
| `transmission` | Transmission type |
| `VIN` | Vehicle Identification Number |
| `drive` | Drive type such as FWD, RWD, or 4WD |
| `size` | Vehicle size classification |
| `type` | Vehicle body type |
| `paint_color` | Exterior paint color |
| `image_url` | Image link associated with the listing |
| `description` | Text description of the listing |
| `county` | County information |
| `state` | State abbreviation |
| `lat` | Latitude coordinate |
| `long` | Longitude coordinate |
| `posting_date` | Date and time when the listing was posted |

## Target Variable
`price`
