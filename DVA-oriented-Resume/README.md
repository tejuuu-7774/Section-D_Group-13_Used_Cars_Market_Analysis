# DVA Capstone – Resume Content

## Project Title
Used Cars Price Prediction and Market Analysis

## Sector
Automotive / Data Analytics

## Problem Statement
Developed a machine learning model to predict used car prices and identify key factors influencing pricing in the resale market.

## Tools and Technologies
- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook / Google Colab
- Tableau Public
- GitHub

## Key Contributions
- Cleaned and processed a dataset of 426,000+ records
- Performed exploratory data analysis to identify pricing trends
- Engineered features for predictive modeling
- Built and evaluated regression models (Linear Regression, Decision Tree, Random Forest)
- Designed KPIs for business insights
- Created Tableau dashboards for visual storytelling

## Resume Bullet Points

- Built a data analytics capstone on used car price prediction using Python, Tableau, and GitHub; cleaned and analyzed 426K+ records, developed KPIs, and delivered dashboard-driven business insights

- Developed and evaluated multiple regression models (Linear Regression, Decision Tree, Random Forest) to predict vehicle prices and improve pricing accuracy

- Performed data cleaning, feature engineering, and exploratory analysis to uncover key drivers such as mileage, vehicle age, and manufacturer impact on pricing

- Designed interactive dashboards in Tableau to visualize pricing trends and support data-driven decision-making
